# 개발 현황

기록일: 2026-11-02

## 구현 범위

- Java 21 / Spring Boot 3.5.7, Next.js 16.2.12 / React 19.2.4 기반이다. 백엔드(`backend`)가 한국투자증권(KIS) Open API를 호출하고, 프론트엔드(`frontend`)는 화면만 담당한다. 프론트의 `/api/kis/*` 요청은 `next.config.mjs` rewrites로 백엔드(8080)에 전달한다.
- 종목 검색(종목명·6자리 코드), 종목 정보(현재가, 전일 대비 원·%, 시가·고가·저가·전일 종가, 원화), 상단 시세를 KIS 실제 값으로 표시한다.
- 실시간 갱신은 폴링 방식이다. 종목 정보 5초, 상단 시세·관심종목 10초, 1일 차트 30초 간격이며 마지막 갱신 시각을 표시한다.
- 선 차트는 1일(분봉 + 실시간 누적), 1주·3개월·1년(일봉)을 제공한다.
- 캔들 차트는 Lightweight Charts로 일봉 OHLC를 그리며 선/캔들 전환 버튼을 제공한다. 상승 빨강, 하락 파랑이다.
- 관심종목은 6자리 코드로 추가·삭제하고 브라우저에 저장하며, 클릭하면 해당 종목으로 이동한다.
- 서버 연결 상태 배지(연결됨/연결 끊김)와 데이터 없음 안내를 표시한다.
- KIS 토큰은 1분 1회 발급 제한 때문에 메모리와 파일에 캐시한다.

## 남은 작업

내일 할 일

- 6번 캔들 차트 모양 확인 (3개월 기준 캔들 길이·간격)
- 8번 예외 처리 확인 (서버 종료 시 "연결 끊김", 재시작 시 "연결됨")
- 캔들 차트를 옆으로 넘기면 아무것도 안 뜨는 원인 확인하고 고치기
- 실시간 갱신을 폴링에서 WebSocket으로 변경하기
- 뉴스 API를 연결해서 뉴스를 실제 데이터로 바꾸기
- 전문가 투자의견, 최근 실적을 수정해서 마무리하기

그 외

- 숫자 색상 통일 (상승 빨강·하락 파랑)
- KIS 앱키·시크릿은 `application-local.properties`에만 두고 깃에서 제외 (`.kis-token`, node_modules, .next, target도 제외)
- DB(MyBatis·MariaDB) 연동은 구현하지 않았다.
- 장 시간 표시는 정규장(평일 09:00~15:30) 기준이며 공휴일, 시간외·NXT 거래는 반영하지 않았다.
