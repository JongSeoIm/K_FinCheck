# 개발 현황

기록일: 2026-11-04

## 구현 범위

- Java 21 / Spring Boot 3.5.7, Next.js 16.2.12 / React 19.2.4 기반이다. 2차에서 MariaDB, Kafka 3.9.2, FastAPI AI 서버(`ai_server`)를 추가했다.
- 회원은 `app_user`, 기업은 `company`, 관심종목은 `watchlist`, 실적은 `financial_report`·`financial_value`에 저장한다. 백엔드 실행 시 `schema.sql`로 없는 테이블과 컬럼을 추가한다.
- 회원가입·로그인·로그아웃은 Spring Security 세션 방식이다. 비밀번호는 BCrypt로 저장하고, 로그인 시 세션 ID를 변경하며, 변경 요청에는 CSRF 토큰을 사용한다.
- 관심종목은 계정별 DB에 저장한다. 관심종목과 챗봇 경로는 로그인이 필요하고, 시세·차트·실적·뉴스는 로그인 없이 볼 수 있다.
- 실시간 시세는 KIS 체결 → Kafka(`stock-quotes-v1`) → 서버 집계 → Push(0.5초)/Polling(2초) 순서로 전달한다. 중복·역순 체결을 제거하고, Kafka 전송 실패 시 10초 동안 바로 전달한다.
- 차트는 1초·5초·30초, 1분·3분·5분·10분·15분·30분·60분, 일·주·월·년을 제공한다. 초·분봉은 서버가 연결 후 받은 체결로 만들고 재시작하면 비워진다. 일·주·월·년봉은 KIS 기간별 조회를 사용한다.
- 선·캔들 차트는 Recharts로 통일했고, 마우스 휠 확대·축소와 표시 범위에 맞는 축 조정을 제공한다.
- 실적은 OpenDART 전체 재무제표의 연결 사업보고서에서 매출액·영업이익·당기순이익을 가져온다. 표준 계정 코드를 먼저 찾고, 없으면 계정명으로 찾는다.
- 실적은 수집 후 1시간 동안 DB에서 재사용한다. 다시 받지 못하면 저장된 자료를 보여 주고 안내 문구를 표시한다. 금액이 없으면 0이 아니라 NULL로 저장한다.
- 최근 실적 패널에 회사명, 사업연도, 연결 기준, 전년 금액, 증감률, 비교 막대, 수집 시각, DART 공시 링크를 표시한다.
- FastAPI에서 OpenAI `gpt-5.4-mini` 답변을 받고, Tool 4개(`get_company_info`, `get_stock_quote`, `get_financial_result`, `get_company_news`)로 Spring 자료를 조회한다.
