# OpenDART 연간 실적 연동

## 현재 구현

- 삼성전자(005930), SK하이닉스(000660)의 연결 사업보고서에서 매출액·영업이익·당기순이익을 조회한다.
- 최근 실적 패널은 연간 실적이다. 분기 실적·실적 예상치·전문가 투자의견은 포함하지 않는다.
- 기본 사업연도는 한국 시간 기준 전년도이며, 현재는 2025년이다. 해당 연도의 사업보고서가 없으면 자료 없음으로 안내하며 이전 연도로 자동 전환하지 않는다.
- 전년 수치는 같은 사업보고서의 비교 수치를 사용한다. 증감률은 (당기-전기)/전기×100이며 전기가 양수일 때만 계산한다. 흑자·적자 전환과 적자 지속은 문구로 표시한다.
- 원 단위 금액은 API에서 문자열로 전달하고, 화면은 억 원 단위로 소수 첫째 자리까지 표시한다.
- 누락·계정 후보 충돌·원화 이외 통화는 0으로 대체하지 않는다. 전년 수치가 없거나 0이면 증감률을 표시하지 않는다.
- 기업 정보는 company, 공시 정보는 financial_report, 세 가지 재무 수치는 financial_value에 저장한다. 원본 계정 ID·계정명·통화·처리 상태도 보관한다.
- 저장된 같은 기업·연도의 최신 연결 사업보고서가 수집 후 1시간 이내이면 DB에서 재사용한다. 자료가 없거나 만료되면 OpenDART에서 다시 수집한다. 서버 재시작 후에도 저장 자료는 유지된다.
- 기업·공시·수치 저장은 한 트랜잭션으로 처리하며 공시 접수번호+연결 구분, 보고서+공통 계정 코드로 중복을 방지한다. 정정 공시가 새로운 접수번호로 들어오면 별도 보관하고 조회 시 접수번호가 가장 최신인 보고서를 선택한다.
- 수집 실패 시 기존 DB 자료를 삭제하지 않는다. 만료된 자료로 자동 대체 응답하지 않고 조회 오류를 안내한다. 기사·실시간 체결·대화 이력 저장은 이번 범위가 아니다.
- collected_at은 UTC 기준으로 저장하며 API fetchedAt은 실제 조회 시각이 아니라 해당 자료의 수집 시각이다.

## 설정 및 실행

백엔드의 Git 제외 파일 `src/main/resources/application-local.yml`에 다음 설정을 추가한다. 실제 키는 프론트엔드·공개 문서·저장소에 넣지 않는다.

```yaml
opendart:
  api-key: YOUR_OPENDART_API_KEY_HERE
```

DB 연결 설정도 준비해야 한다. 새 DB에는 프로젝트 database/schema.sql을 실행한다. 기존 DB에는 database/migrations/001_financial_value_status.sql을 한 번 실행해 누락·모호 상태 저장 컬럼을 추가한다. 현재 개발 PC에는 해당 컬럼 적용을 완료했다.

백엔드를 재시작하고 기존 프론트엔드에서 종목을 선택하면 최근 실적이 표시된다. 처음 조회 시 두 지원 기업의 기업·공시·실적을 자동으로 저장한다. 별도 관리자 수집 화면은 아직 없다. 기존 실시간 서버 실행 방법은 `실시간_시세_실행_가이드.md`를 따른다.

## 조회 API

`GET /api/stocks/{stockCode}/financials?year=2025`

`year` 생략 시 전년도. 2015년부터 전년도까지만 조회 가능하다.

- 응답: 기업·사업연도·전년도·보고서 코드(11011)·연결 구분(CFS)·통화·공시 접수번호·공시 링크·수집 시각·세 가지 실적
- 항목별 응답: 원 단위 당기/전기 금액, 증감률, 비교 상태, 계정 상태, 원본 계정 ID·계정명·통화
- 오류: 미지원 종목/보고서 없음 404, 연도 범위 오류 400, 인증키 미설정 503, 공시 서버·인증·호출 제한 오류 502, DB 조회·저장 오류 503
- 인증키가 포함될 수 있는 외부 요청 원본 예외와 오류 메시지는 클라이언트에 전달하거나 로그로 남기지 않는다.

## 확인한 결과

2026-11-02 로컬 검증에서 두 기업 모두 2025년 연결 사업보고서의 세 항목과 전기 비교 수치가 실제 조회되었다. 브라우저에서 종목 변경에 따른 실적·공시 링크 전환도 확인했다.

후속 DB 저장 검증:

- 금융 단위 테스트 5개·실제 DB 저장 테스트 2개·기존 인증/DB/시세 컨트롤러 관련 테스트 7개, 총 14개 통과. 자동 테스트의 임시 자료는 롤백했다.
- 실제 2025년 두 기업의 공시 2건·재무 수치 6건 저장을 확인했다.
- 검증 서버를 재시작하고 OpenDART 키를 비활성화한 상태에서 두 기업의 동일 수집 시각·동일 재무 수치가 반환되는 것을 확인했다.
- 기존 화면의 응답 필드는 유지하며 원본 근거 필드만 추가했다. 이번 DB 저장 변경에는 프론트엔드 코드 변경·전체 UI 빌드를 수행하지 않았다.
