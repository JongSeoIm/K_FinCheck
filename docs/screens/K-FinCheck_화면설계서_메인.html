화면 동작
종목을 선택하면 해당 종목의 시세·차트·기업 정보를 갱신한다.
회원 전용 기능은 로그인 후 이용하며, 화면 하단의 뉴스·실적은 KFC_UI_002에서 설명한다.

예외 상태
검색 결과 없음·조회 중·자료 없음·조회 실패를 구분한다.
차트는 확보된 데이터 범위에서 표시하며, 확인되지 않은 값을 임의로 만들지 않는다.

번호영역 및 동작
1로그인·로그아웃
인증 상태에 따라 로그인 또는 로그아웃을 표시한다.
2종목 검색
기업명·종목 코드로 검색하고 결과에서 종목을 선택한다.
3종목 목록
지원 종목을 선택하여 해당 종목 화면으로 전환한다.
4종목·시세 정보
현재가·등락·시가·고가·저가·거래량과 기준 시각을 표시한다.
5주가 차트
선·캔들, 주기, Push·Polling을 전환하고 휠로 확대·축소한다.
6관심 종목
로그인 후 계정별로 등록·조회·삭제하며 종목 선택 시 화면을 전환한다.
7AI 질문
로그인 후 선택 종목의 AI 대화 패널을 연다.
8증권사 투자의견
증권사별 발표 의견·목표주가·발표일과 비교 기준을 표시한다.
