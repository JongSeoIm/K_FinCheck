# 화면설계서 상태

## 현재 기준

- `K-FinCheck_화면설계서_메인.*`은 Push 전용화 이전 문구가 남은 과거 화면설계서다. 현재 실시간 차트는 WebSocket Push로 고정되어 있으며 Push·Polling 선택 UI를 제공하지 않는다.
- `K-FinCheck_화면설계서_기업정보.*`은 제거된 네이버 뉴스 화면을 포함한 과거 화면설계서다. 현재 기능의 요구사항이나 구현 근거로 사용하지 않는다.
- 현재 종목 화면의 산업·정책 영역은 `PolicyFeed.jsx`와 실제 실행 화면을 기준으로 확인한다.

## 다음 갱신

조선비즈 RSS 목록·일회성 요약 UI를 실제로 구현하고 브라우저 검증을 마친 뒤 다음 내용을 반영해 화면설계서 HTML·PNG·PDF를 함께 교체한다.

- 기존 `산업·정책 동향` 패널
- 별도 `최신 기사` 패널
- 제목 키워드 기준 `직접 관련`·`산업 관련` 배지
- 원문 링크와 일회성 요약 버튼
- `일회성 AI 요약·저장되지 않음` 안내

구현 전에는 예상 화면을 완료된 실제 화면처럼 문서에 넣지 않는다.
