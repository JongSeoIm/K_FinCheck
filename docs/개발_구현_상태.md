# 개발 구현 상태 (dev/kbean7)

기록일: 2026-11-04

## 구현 범위

- Java 21 / Spring Boot 3.5.7, Next.js 16.2.12 / React 19.2.4, FastAPI, MariaDB(MyBatis).
- KIS 현재가·차트, 종목 검색, NAVER 관련 기사, OpenDART 연간 실적(DB 저장), 투자의견·목표가.
- 회원가입·로그인·로그아웃(BCrypt, 세션, CSRF)과 계정별 관심종목.
- 서버 시세 저장소와 Polling/Push 선택, 초·분·일·주·월·년 차트.
- 로그인 사용자용 AI 챗봇(조회 Tool 4개, 출처 표시, 최근 10개 대화 문맥).
- 지원 종목은 삼성전자(005930), SK하이닉스(000660), NAVER(035420)다.

## 확인한 결과

- 사용자 로컬: 로그인·관심종목 유지·비밀번호 암호화, 챗봇 답변과 출처, 체결 시각, 누적거래량, Polling/Push 전환, 1분 선 차트, 60분 캔들.
- FastAPI 테스트 14개 통과.

## 제외 및 남은 작업

- 실제 키, `application-local.properties`, `.kis-token`, `ai_server/.env`, `ai_server/.venv`는 Git에서 제외한다.
- 미구현: KIS 실시간 체결 구독·Kafka, 실시간 봉의 DB 저장, 비밀번호 변경·탈퇴, 지원 종목 확대.
- 투자의견(KFC-020)은 자료상 보류이며 KIS 데이터의 사용·표시 조건 확인이 필요하다.
- 투자의견 점수는 매수 의견 비율이라 3종목 모두 100으로 표시된다.
- `company.company_name`에는 DART 법인명(예: `삼성전자(주)`)이 저장되고 화면 표시명은 `market.js`를 따른다.
