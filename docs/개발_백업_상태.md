# 개발 백업 상태

기록일: 2026-11-02

## 구현 범위

- Java 21 / Spring Boot 3.4.3, Next.js 16.2.12 / React 19.2.4 기반 기존 현재가·기간별 OHLC 조회와 국내 종목 화면을 유지한다.
- 삼성전자·SK하이닉스 KIS 실시간 체결 → Kafka → Spring 최신 시세·봉 집계 → WebSocket Push / HTTP Polling을 추가했다.
- 초·분봉은 연결 이후 실제 수신한 체결로 생성하며 각 주기 최근 120개 봉을 메모리에 보관한다. 전체 장중 이력 복원과 실시간 봉의 DB 영구 저장은 구현하지 않았다.
- 선·캔들 차트 휠 확대/축소, 표시 범위에 따른 가격축 조정, 확대 정도에 따른 HH:mm:ss 시간축을 구현했다.
- 두 기업의 OpenDART 연결 사업보고서에서 연간 매출액·영업이익·당기순이익 및 전년 비교 수치를 조회한다. 기업·공시·수치·원본 계정 근거를 MariaDB에 저장하고 수집 후 1시간 이내 자료는 DB에서 재사용한다. 기본 사업연도는 전년도다.
- 최근 실적 패널은 증감률 색상·굵은 글씨, 전년/당해 회색 비교 막대, 원본 공시 링크를 제공한다.
- 종목 대화 버튼과 오버레이 패널은 UI만 구현되어 있으며 실제 LLM은 연결되지 않았다. 전문가 투자의견은 준비 화면이며, 국내 뉴스는 NAVER API HUB와 연결했다.

- MariaDB·MyBatis로 연결하며 회원가입·로그인·로그아웃은 BCrypt·서버 세션·CSRF를 사용한다. 관심 종목은 계정별 DB에 저장한다.
- 로그인/회원가입은 기존 무채색·각진 UI다. 상단은 왼쪽 로그인/로그아웃 텍스트, 오른쪽 종목 검색이며 사용자 이름은 숨긴다. 종목 정보 높이를 줄이고 관심 목록에 종목명·가격·등락률을 표시한다.

## 확인한 결과

- 실시간 파서·봉 집계·중복/역순 처리·수신 상태·내장 Kafka→WebSocket/Polling 통합 및 기존 컨트롤러 관련 테스트 총 9개가 이전 작업 단계에서 통과했다.
- 실제 KIS에서 두 기업 체결 수신과 Kafka READY, 브라우저 가격·거래량·5초봉 갱신 및 Polling/Push 전환을 확인했다.
- 차트 휠 확대/축소와 확대 정도에 따른 시간축 간격 변화를 브라우저에서 확인했다.
- 별도 복사본에서 프론트엔드 Webpack 프로덕션 빌드를 이전 단계에 확인했다. 이후 실적 UI 수정까지 포함한 전체 빌드는 다시 실행하지 않았다.
- OpenDART 관련 단위 테스트 5개가 통과했고 실제 두 기업의 2025년 연결 실적 및 전기 비교 수치 조회를 확인했다.
- 실적 종목 전환·공시 링크·막대 비율·패널 넘침 없음·증감률 13px 및 굵기 700을 브라우저에서 확인했다. 관련 컴포넌트 ESLint도 통과했다.
- 위 결과는 각 개발 단계의 검증 기록이며 이번 Git 백업을 위해 전체 테스트를 재실행한 결과는 아니다.

- 후속 기업·실적 DB 저장 단계에서 관련 테스트 14개 통과. 실제 공시 2건·수치 6건 저장 후 외부 공시 키 비활성·서버 재시작 상태에서도 같은 DB 자료 재조회 확인.
- 회원가입·로그인·계정별 관심 목록 저장·새로고침 유지·로그아웃을 실제 DB 및 브라우저에서 확인했고 임시 계정은 정리했다. 이 단계의 프론트엔드 Webpack 빌드를 확인했으며 이후 단순 상단 배치 수정은 ESLint·화면으로 검증했다.
- 네이버 실제 두 기업 기사 각 10건, 종목 전환·5분 캐시 재사용을 확인했다.

## 실행 안내

- 실시간 실행: [실시간 시세 실행 가이드](실시간_시세_실행_가이드.md)
- 연간 실적 설정 및 범위: [OpenDART 연간 실적 연동](OpenDART_연간_실적_연동.md)
- Docker Compose 구성은 현재 환경에 Docker가 없어 실행 검증하지 않았다. 내장 Kafka 실행은 검증했다.

- DB 구조는 database/schema.sql, 기존 DB 상태 컬럼 추가는 database/migrations/001_financial_value_status.sql을 사용한다. 실제 DB 계정·비밀번호 설정은 공유하지 않는다.
- 신규 연결/계정/뉴스 설정은 docs의 해당 연결 가이드를 참고한다.

## 제외 및 남은 작업

- 실제 인증키·환경 설정·토큰, node_modules, .next, target, IDE 설정과 scratch는 제외한다. README는 변경하지 않는다.
- 실제 AI 연동, 전문가 투자의견, 실시간 체결/봉 영구 저장, 장시간 부하·장외/장애 복구·다양한 모바일 검증은 별도 작업이다.
- 분기 실적과 주·월·년봉의 실시간 합성은 포함하지 않는다.
