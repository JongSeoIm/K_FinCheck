# 개발 백업 상태

기록일: 2026-11-02

## 포함 범위

- backend: Java 21 / Spring Boot 3.4.3, 헬스체크, KIS 인증·토큰 재사용, 현재가·기간별 OHLC 조회 API와 관련 테스트 소스.
- stock_dashboard: Next.js 16.2.12 / React 19.2.4 기반 국내 종목 화면, 백엔드 시세 연동, Recharts 선·캔들 차트.
- 종목 대화 버튼과 오른쪽 오버레이 패널은 UI만 구현되어 있다. 실제 LLM은 연결되지 않았다.
- 차트 선택 목록은 1초·5초·30초·1분·3분·5분·10분·15분·30분·60분이다. 초·분봉 조회는 아직 구현되지 않았으며 현재 선택 시 일봉 요청으로 처리된다.
- 공통 스크롤바 숨김 스타일을 포함한다. 스크롤 기능은 유지한다.

## 확인한 결과

- 실행 화면에서 삼성전자 현재가 및 일봉 45개 수신을 확인했다. KIS 원본 수치와의 별도 대조는 하지 않았다.
- Recharts 3.x 좌표 훅 적용 후 캔들 몸통·꼬리 45개 생성 및 선 차트 표시를 확인했다.
- 대화 패널 열기·닫기·Escape·입력·재열기 시 대화 유지와 배경 차트 크기 유지를 확인했다.
- 차트·대화 패널·Dashboard·layout의 관련 ESLint 검사는 통과했다. 이후 주기 목록 변경에 대해서도 StockChart ESLint 검사가 통과했다.
- 스크롤바 CSS의 괄호·인코딩·공백 검사를 수행했다. 해당 스타일 변경 후 브라우저 재확인은 하지 않았다.
- 이번 백업에서는 Maven 테스트와 전체 프론트엔드 빌드를 새로 실행하지 않았다. 과거 작업 로그의 통과 결과를 이번 검증으로 간주하지 않는다.

## 제외한 항목

- 실제 인증키·환경 설정·접근토큰 파일, node_modules, .next, target, IDE 설정, scratch.
- 기존 README와 미검증 작업 로그는 이번 백업에서 변경·추가하지 않았다.

## 남은 작업

- 실시간 WebSocket 수신·Kafka 전달·Polling/Push 통합 검증.
- 실제 초·분봉 데이터 구현 및 주·월·년봉의 별도 검증.
- DB·OpenDART·실제 AI·뉴스 연결.
- 비밀값이 없는 환경에서 단위 테스트와 빌드 재검증, 모바일 및 오류 상태 검증.
