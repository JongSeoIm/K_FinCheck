## 6. 캔들 차트 SVG 렌더링 버그 수정 및 주기 선택 UI 개편 (완료)
- **현상**:
  1. Recharts 3.x 환경에서 `<Customized component={CandlestickLayer} />` 내부에서 데이터 객체 참조가 비어 있어 캔들이 렌더링되지 않던 문제.
  2. KIS 실전 API의 초당 거래건수 제한(1~2건)으로 인해 빠른 탭 전환 또는 다중 호출 시 `500 EGW00201: 초당 거래건수를 초과하였습니다` 에러가 발생하여 차트 데이터가 비어버리던 문제.
  3. 주기 선택 UI가 어두운 캡슐 박스 형태로 되어 있어 `캔들 차트 · 선 차트` 텍스트 링크 스타일과 이질감이 있던 문제.
- **수정 및 보완 파일**:
  1. `backend/src/main/java/com/kfincheck/client/KisApiClient.java`:
     - KIS API 호출 간 최소 요청 간격(250ms) 제어(`paceRequest`) 추가.
     - `EGW00201`(초당 거래건수 초과) 오류 수신 시 600ms 대기 후 자동 1회 재시도(Backoff Retry) 로직 추가로 오류 완전 방지.
  2. `backend/src/main/java/com/kfincheck/service/StockService.java`:
     - 단기 인메모리 캐시 적용 (현재가 3초, 차트 데이터 25초)으로 연속 탭 전환 시 중복 KIS 호출을 제거하고 0ms 즉각 응답.
  3. `stock_dashboard/src/app/components/StockChart.jsx`:
     - `CandlestickLayer`에 `candles` 데이터를 명시적으로 주입하고, Recharts가 계산한 포인트(`points`)와 스케일을 이중으로 참조하여 캔들 막대(양봉 빨강 `#c43b3b`, 음봉 파랑 `#1769aa`, 꼬리선)가 즉시 렌더링되도록 수정.
     - 주기 선택 UI를 `캔들 차트 · 선 차트`와 동일한 글씨 클릭형 밑줄 탭(`1분 ⌄ · 일 · 주 · 월 · 년`)으로 변경.
  4. `stock_dashboard/src/app/globals.css`:
     - 검은색 캡슐 박스를 제거하고 `.range-tabs` 텍스트 버튼, 파란색 밑줄(`border-bottom: 2px solid #1769aa`), 중간 구분점(`·`), 화이트 톤 드롭다운 팝오버 스타일 적용.
- **검증 결과**:
  1. 백엔드 연속 호출 및 캐시 검증: 현재가 및 일·주·월봉 API 연속 호출 시 `EGW00201` 오류 없이 HTTP 200 정상 반환 확인.
  2. 백엔드 단위 테스트: `mvn test` 전체 통과 (`BUILD SUCCESS`).
  3. 프론트엔드 프로덕션 빌드: `npm run build` 통과 (`✓ Compiled successfully in 5.0s`).
  4. 백엔드 및 프론트엔드 데몬 정상 구동 중 (`http://localhost:3000`, `http://localhost:8080`).

## 57. 언론 RSS 이용 범위·일회성 요약 설계 정리 (2026-11-13)

- 네이버 뉴스 API·화면·AI Tool은 현재 기능에서 제거된 상태를 유지한다. 2026-11-03의 뉴스 구현 기록은 당시 개발 이력이며 현재 기능 설명으로 사용하지 않는다.
- 조선비즈는 공식 RSS의 제목·링크·발행 시각만 서버 메모리에 임시 보관하고, 제목 키워드로 기업 직접 언급과 산업 관련을 단순 분류하는 다음 구현 범위로 정했다.
- 기사 본문은 사용자가 요약을 요청한 한 건만 일시 조회해 2~3문장으로 처리한다. 원문·중간 데이터·임베딩·요약문은 DB·파일·기존 대화 이력에 저장하지 않는다.
- 산업통상부·정책브리핑은 허용된 공식 문서를 DB에 보관해 정책 질문에 사용하는 RAG이고, 조선비즈는 휘발성 RSS 목록과 선택 기사 요약이므로 API와 화면을 분리한다.
- 기존 `산업·정책 동향` 아래 별도 `최신 기사` 패널을 두고 분류 배지·원문 제목·출처·발행 시각·원문 링크·요약 버튼을 표시하는 방향이다. 실제 RSS 수집·요약 API·화면 코드는 아직 구현하지 않았다.
