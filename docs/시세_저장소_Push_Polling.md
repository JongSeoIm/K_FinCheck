# 시세 저장소와 Push·Polling

## 현재 코드

- `QuoteCollector`가 KIS 현재가를 1초에 1번씩 종목을 돌아가며 조회해 `QuoteStore`(서버 메모리)에 둔다.
  - 장중 종목당 2.5초 간격, 장 외 60초 간격이다.
  - KIS가 초당 한도(`EGW00201` 또는 "초당" 문구)를 응답하면 5초 쉰다.
- `QuoteStore`는 종목별 최신 시세를 보관한다. 순번(`seq`)으로 중복·역순 값을 버린다. 초 단위 샘플은 장중에 누적거래량이 바뀐 경우에만 쌓는다.
- Polling: `GET /api/quote/state?codes=` 응답을 받은 2초 뒤 다시 요청한다. KIS를 호출하지 않고 저장소 값을 읽는다.
- Push: WebSocket `/ws/stock`이 0.5초마다 저장소 값을 보낸다. 허용 출처는 `localhost:3000`, `127.0.0.1:3000`이다. 연결이 끊기면 3초 뒤 재연결한다.
- 화면의 `FeedControl`에서 Polling/Push를 고른다. 선택은 `localStorage`의 `kfc-feed-mode`에 기억하며 전환하면 이전 연결을 정리한다. 연결 상태가 표시된다.
- 상단 티커, 관심 목록, 종목 정보가 같은 스토어 값을 쓴다.
- 시세 표시에는 현재가, 등락, 시·고·저가, 전일 종가, 누적거래량, 마지막 체결 시각, 조회 시각, 출처가 있다. 상승은 빨강, 하락은 파랑이다.
- 마지막 체결 시각은 `GET /api/kis/trade-time/{code}`(KIS `FHPST01060000`)로 가져오며, 응답에 날짜가 없어 요일·시간으로 추정한다.

## 검증 상태

- 사용자 로컬에서 확인: Polling/Push 전환과 연결 상태 표시, 티커·관심 목록 공유, 누적거래량·출처 표시.
- 값은 종목당 약 2.5~3초 주기로 바뀐다.
- 공휴일에는 체결 날짜 추정이 틀릴 수 있다.
