# K_FinCheck 실행 가이드

## 1. 준비물

| 항목 | 버전 | 용도 |
|---|---|---|
| JDK | 21 | Spring Boot 백엔드 |
| Node.js | 20.9 이상 | Next.js 프론트엔드 |
| Python | 3.10 이상 | AI 서버(FastAPI) |
| MariaDB | 10.x 이상 | 회원·관심종목·기업·실적 저장 |
| Git | 최신 | 소스 관리 |

Kafka는 현재 사용하지 않는다.

## 2. 키 발급

| 서비스 | 용도 | 넣는 곳 |
|---|---|---|
| KIS Open API (앱키·시크릿) | 시세·차트·투자의견·체결 시각 | `backend/src/main/resources/application-local.properties` |
| NAVER API HUB (Client ID·Secret) | 관련 기사 | 위와 같음 |
| OpenDART (API 키) | 연간 실적 | 위와 같음 |
| OpenAI (API 키) | AI 챗봇 | `ai_server/.env` |

키와 비밀번호는 git에 올리지 않는다. 설정 예시: `application-local.properties.example`, `ai_server/.env.example`

## 3. DB 준비 (최초 1회)

1. MariaDB에서 데이터베이스를 만든다.
   ```sql
   CREATE DATABASE kfincheck DEFAULT CHARACTER SET utf8mb4;
   ```
2. `kfincheck`를 선택하고 SQL을 **순서대로** 실행한다.
   1. `backend/sql/kfincheck_earnings.sql` (company, financial_report, financial_value)
   2. `backend/sql/kfincheck_auth.sql` (app_user, watchlist, 지원 종목 3개)
3. `application-local.properties`에 DB 주소와 계정을 넣는다.

## 4. 설정 파일 만들기

```
copy backend\src\main\resources\application-local.properties.example backend\src\main\resources\application-local.properties
copy ai_server\.env.example ai_server\.env
```
각 파일을 열어 키와 DB 정보를 채운다.

## 5. 실행 순서

터미널을 3개 연다. 프로젝트 폴더 기준이다.

| 순서 | 서버 | 명령 | 주소 |
|---|---|---|---|
| 1 | 백엔드 | `cd backend` → `.\mvnw.cmd spring-boot:run` | http://localhost:8080 |
| 2 | AI 서버 | 아래 5-1 | http://127.0.0.1:8000 |
| 3 | 프론트 | `cd front_end` → `npm install` → `npm run dev` | http://localhost:3000 |

### 5-1. AI 서버
```
cd ai_server
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```
키·모델 확인: `Invoke-RestMethod http://127.0.0.1:8000/health/model` → `ok: True`

## 6. 실행 확인

| 기능 | 확인 방법 |
|---|---|
| 시세·차트 | 삼성전자 화면에서 현재가, 시가·고가·저가·누적거래량, 차트 표시 |
| 체결 시각 | 현재가 아래 "마지막 체결" 표시 (장중) |
| 회원가입·로그인 | 가입 → 로그인 → 상단에 닉네임 표시 |
| 관심종목 | 추가 → 새로고침·재로그인 후 유지, 로그아웃 시 비워짐 |
| 기사·실적·투자의견 | 오른쪽·아래 패널에 표시 |
| AI 챗봇 | 로그인 후 "삼성전자 현재가 알려줘" → 출처·기준 시각 표시 |

## 7. 자주 나는 문제

| 증상 | 확인 |
|---|---|
| 백엔드가 DB 오류로 멈춘다 | `application-local.properties`의 DB 주소·계정, MariaDB 실행 여부 |
| 챗봇이 "AI 서버에 연결하지 못했습니다" | AI 서버 실행 여부(포트 8000) |
| `OPENAI_API_KEY 가 설정되지 않았습니다` | `ai_server/.env` 저장 여부, 서버 재시작 |
| API가 404 | 프론트 `next.config.mjs` 변경 후 `npm run dev` 재시작 |
| 실적이 안 나온다 | DART 키, 지원 종목 3개(삼성전자·SK하이닉스·NAVER) |

## 8. 보안 수칙

- `application-local.properties`, `.kis-token`, `ai_server/.env`는 커밋하지 않는다. 커밋 전 `git status`로 확인한다.
- 비밀번호는 BCrypt 해시로만 저장한다.
- 챗봇·관심종목 API는 로그인한 사용자만 호출할 수 있다.
