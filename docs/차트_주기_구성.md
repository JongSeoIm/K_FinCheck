# 차트 주기 구성

## 현재 코드

- API: `GET /api/chart/{code}?interval=` 값은 `1s 5s 30s 1m 3m 5m 10m 15m 30m 60m D W M Y`다.
- 1·5·30초: 서버가 수집한 샘플로 만든다. 서버를 시작한 뒤 수신한 값이며 재시작하면 사라진다. 값이 바뀐 시점에만 봉이 생겨 듬성듬성하다.
- 1~60분: KIS 당일 1분봉을 주기에 맞게 묶고 현재 진행 중인 값을 합친다. 오늘 데이터만 있다.
- 일·주·월·년: KIS `inquire-daily-itemchartprice`의 기간 구분(`D/W/M/Y`)으로 가져오며 서버에서 10분간 캐시한다.
- 화면: 선 차트(`StockChart.jsx`, Recharts)와 캔들 차트(`CandleChart.jsx`, Lightweight Charts). 선 차트는 휠 확대·축소, 끌어서 이동, 전체 보기를 직접 구현했다. 분 단위 캔들은 시간을 한국 시각(+9시간)으로 보정해 그린다.
- 색은 상승 빨강(`#d6453d`), 하락 파랑(`#2f6fdb`)이다. 전일 종가는 상단 시세와 같은 값을 쓴다.
