# 회원가입·로그인·관심종목 연동

## 현재 코드

- 회원가입: 아이디·비밀번호·닉네임을 검증한 뒤 `app_user`에 저장한다. 비밀번호는 BCrypt 해시만 저장한다.
- 로그인: Spring Security 6에서 직접 처리하고 서버 세션을 쓴다. CSRF는 `XSRF-TOKEN` 쿠키와 `X-XSRF-TOKEN` 헤더로 확인한다.
- 로그아웃 시 세션과 챗봇 대화 문맥을 지운다.
- 인증이 필요한 경로는 `/api/watchlist/**`, `/api/chat/**`이고 나머지는 열려 있다.
- 관심종목은 계정별로 `watchlist` 테이블에 저장한다. 새로고침과 재로그인 후에도 유지되고 로그아웃하면 화면 목록이 비워진다.
- 프론트엔드는 `lib/api.js`의 `apiFetch`로 CSRF 토큰을 붙이며 403이 오면 한 번 재시도한다.
- 상태는 zustand 스토어(`useStockStore.js`)에 있고, 관심 목록 패널은 `WatchlistPanel.jsx`다.

## API

| 경로 | 설명 |
|---|---|
| `POST /api/auth/signup` | 회원가입 |
| `POST /api/auth/login` | 로그인 |
| `POST /api/auth/logout` | 로그아웃 |
| `GET /api/auth/me` | 로그인 상태 |
| `GET /api/watchlist` | 내 관심종목 |
| `POST /api/watchlist` | 추가 |
| `DELETE /api/watchlist/{code}` | 삭제 |

## DB 설정

1. `backend/sql/kfincheck_earnings.sql` (company 테이블)
2. `backend/sql/kfincheck_auth.sql` (app_user, watchlist, 지원 종목 3개 seed)

두 파일 모두 여러 번 실행해도 안전하다. 실제 DB 계정·비밀번호는 `application-local.properties`에 넣고 Git에 올리지 않는다.

## 검증 상태

- 사용자 로컬에서 확인: 가입, 로그인 이동, 관심종목 추가 후 새로고침 유지, 로그아웃, DB에 비밀번호가 암호화되어 저장됨.
- 관심종목은 `company`에 있는 종목만 등록할 수 있다 (지원 종목 3개).
